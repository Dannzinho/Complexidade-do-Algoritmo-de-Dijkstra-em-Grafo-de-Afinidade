# Complexidade-do-Algoritmo-de-Dijkstra-em-Grafo-de-Afinidade
Revisão da literatura sobre a complexidade do algoritmo de Dijkstra, com um estudo de caso complementar no Player2, app do grupo que recomenda usuários por afinidade via grafo ponderado. A revisão é a base do trabalho; a medição do Dijkstra no Player2 em diferentes tamanhos de grafo serve para comparar o tempo real com o que a literatura e a notação assintótica apontam.
