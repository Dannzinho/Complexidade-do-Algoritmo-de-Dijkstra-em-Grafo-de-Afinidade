# Complexidade-do-Algoritmo-de-Dijkstra-em-Grafo-de-Afinidade
O projeto usa o Player2, app do grupo que recomenda usuários por afinidade via grafo ponderado, como estudo de caso. A proposta é implementar e medir o Dijkstra nesse grafo em diferentes tamanhos de entrada, comparando o tempo real com a notação assintótica estudada na disciplina.
